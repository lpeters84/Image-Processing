# Image-Processing
Post-processing of an ultrasound image

![Before After](https://github.com/user-attachments/assets/67004f40-2bf1-4d75-bffe-2958efb61969)

# Data Description
Liver_Ultrasound.png is the raw image taken from the ultrasound without any real time filtering 

# Code Description
The code runs through a series of image processing techniques to remove the "salt and pepper noise", increase the colour contrast of the image, and sharpen the blurred edges in the image.
